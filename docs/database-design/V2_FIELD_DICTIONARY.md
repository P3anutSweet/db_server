# V2字段字典

这是研究修订草案，不是已建成的Teable表或已实现的约束。

## 业务渠道

一个下单业务渠道；不默认等同客户公司或市场。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 渠道编码 | text | 稳定唯一编码 |
| 渠道名称 | text | 用户确认的渠道名称 |
| 市场 | singleSelect | 来自已核对的市场，不凭市场自动生成渠道 |
| 客户名称待核对 | text | 可为空；客户公司主数据以后单独规范 |
| 业务负责人 | user | 执行导入的账户不自动成为业务负责人 |


## 产品SKU

一个正式物料号代表的可下单产品；型号系列不是交易行主键。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 料号 | text | 业务标识；记录ID独立且不可变 |
| 品牌 | singleSelect | 雷神/机械师等 |
| 中文描述 | longText | 保留规范描述 |
| 英文描述 | longText | 缺失不猜测 |
| 主品类 | singleSelect | 多标签冲突经确认后规范 |
| 原品类及业务标签 | multipleSelect | 全部保留原标记 |
| 基础计量单位 | singleSelect | 件/套等必须明确；来源未给出时待确认 |
| 制造商 | text | 独立于品牌/供应商/ODM |
| 供应商 | text | 原字段保留 |
| ODM | text | 原字段保留 |
| PID原文 | text | 0有效；USB用途台账第二阶段处理 |
| 已确认版本属性 | longText | 颜色/轴体/布局/语言/套装等经确认记录，不凭名称自动拆分 |

- 经确认的品牌+料号是候选唯一业务键；所有交易以不可变记录ID关联。

## 包装规格

一个SKU的一种包装层级和装量版本。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 产品SKU | linkOne → skus | 正式规格必须关联SKU |
| 包装层级 | singleSelect | 单件/内盒/外箱等 |
| 每包装基础数量 | decimal | 正数；未确认装量时不得作为换算依据 |
| 规格版本 | text | 装量改变新建版本，不回写历史单据 |
| 换算已确认 | checkbox | 原自由文本箱规不能直接视为已确认换算 |
| 原箱规描述 | text | 保留原文 |

- 包装主数据改变不得改变已确认单据上的换算快照。

## 条码分配

一个编码的分配/核对记录；预留码允许尚无SKU或包装。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 条码原文 | text | 保留前导零 |
| 编码体系 | singleSelect | GTIN13/GTIN14/其他内部码/待确认 |
| 规范GTIN | text | 仅校验通过的GTIN规范成14位比较键；原文保留 |
| 产品SKU | linkOne → skus | 待补料号或预留时可空 |
| 包装规格 | linkOne → packaging | 包装对应关系经确认，不任取一个同SKU条码 |
| 分配状态 | singleSelect | 预留/已分配/公式待计算/待核对/停用 |
| 校验状态 | singleSelect | 长度、校验位、对应关系分别验证 |
| 来源行 | linkOne → source_rows | 原始证据 |

- 同料号多码先核对包装/编码主体/历史差异，不能直接宣称是历史版本。

## 基地仓库

一个实际发生渠道提货或退回的地点。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 基地仓库编码 | text | 唯一编码 |
| 基地仓库名称 | text | 正式名称 |
| 可使用 | checkbox | 停用不删除历史引用 |

- 这里只记录交接地点；没有完整收发存数据时不得声称能计算可用库存。

## 渠道订单批次

用户确认：一个业务渠道下单编号；可跨月、包含多个SKU。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 订单批次号 | text | 正式渠道下单编号；不是随意的分组备注 |
| 业务渠道 | linkOne → channels | 已确认订单必须明确渠道 |
| 渠道下单日期 | date | 未知不补成导入日 |
| 订单状态 | singleSelect | 草稿/已确认/暂停/已关闭/已取消 |
| 原表批次文字 | text | 缩写/日期描述/缺失字段先核对为正式编号 |
| 负责人 | user | 业务负责人 |
| 来源行 | linkMany → source_rows | 可由多条旧行核对归并 |

- 默认唯一范围为渠道+批次号；是否全公司唯一仍待确认。
- 月份和SKU都不是批次主键的一部分；更改排期不新建同一订单。
- 正式渠道订单和向基地提交预测是独立过程。

## 批次SKU明细

一个批次内一个明确的SKU及交易要求行；不是一个月份一行。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 渠道订单批次 | linkOne → order_batches | 确认后必填 |
| 批次内行号 | integer | 与批次组合唯一；不同要求的同SKU可多行 |
| 产品SKU | linkOne → skus | 确认后必填 |
| 订单描述快照 | longText | 下单时名称不随主数据改变 |
| 客户版本及要求 | longText | 颜色/语言/轴体等不同要求不强行合并 |
| 明细性质 | singleSelect | 常规/赠品/备品/其他；数量和指标分别过滤 |
| 原始下单数量 | decimal | 基础单位数量；确认后按受控变更调整 |
| 基础单位快照 | text | 明确件/套等 |
| 当前确认数量 | derived | 原始数量+已确认增减单 |
| 已关闭余量 | derived | 关闭-重新开放，不能伪装成已提货 |
| 累计实际提货 | derived | 期初+已确认未冲销的实际提货分配 |
| 实际退回基地 | derived | 真实退回，区别于录入错误的冲销 |
| 净提货量 | derived | 累计实际提货-实际退回 |
| 已履约数量 | derived | 实际提货-需要补提的退回量，含已确认期初 |
| 待提货 | derived | 当前确认数量-关闭余量-已履约数量；期初未知时为空 |
| 提货状态 | derived | 未提/部分提/提货完成/超提异常；与订单状态独立 |
| 来源行 | linkMany → source_rows | 多个原排期行归并后仍可追溯 |

- 同一SKU不同交期通常属于同一明细的多个计划；不能靠源行号生成新业务身份。
- 是否合并相同SKU须先确认交易要求、单位和源数量不是重复快照。

## 分月计划

某条SKU明细在一个计划节点、期间/日期上的数量版本。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 批次SKU明细 | linkOne → order_lines | 计划始终从属于正式明细 |
| 计划节点 | singleSelect | 基地预测/预计提货/预计客户交付/原计划节点待核对 |
| 计划年月 | text | YYYY-MM；跨年可辨，不能只填10月 |
| 预计具体日期 | date | 可空；只有月份时不伪造某一天 |
| 计划数量 | decimal | 基础单位量，不是新增订单数量 |
| 基地预测提交状态 | singleSelect | 未提交/部分提交/已提交/不适用 |
| 基地预测提交日期 | date | 原J列对应节点先核对 |
| 版本状态 | singleSelect | 有效/已替代/已取消 |
| 替代旧计划 | linkOne → line_plans | 保留改期历史，不能让新旧版本同时计入 |
| 改期说明 | longText | 记录原因 |

- 待提交基地预测不等同渠道尚未下单。
- 不同计划节点单独统计，不把预测+提货计划+客户交付计划相加。
- 提货时间不固定时允许没有具体日期；实际提货不强制关联一个预定日期。

## 提货退回单

一次基地与渠道的交接凭据；一张单可含多个SKU和多个订单批次。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 交接单号 | text | 稳定唯一编号 |
| 单据类型 | singleSelect | 实际提货/实际退回/错误冲销 |
| 业务渠道 | linkOne → channels | 同张单据为同一渠道 |
| 基地仓库 | linkOne → warehouses | 同张单据为同一交接地点 |
| 实际交接日期 | date | 发生时登记，不要求预先排定 |
| 单据状态 | singleSelect | 草稿/已确认/已冲销 |
| 确认时间 | dateTime | 实际业务日期与系统确认时间分开 |
| 交接凭据 | attachment | 提货单/退回单等 |
| 冲销原单 | linkOne → handover_docs | 错误冲销必须指向原单；不是实物退货 |

- 草稿不计数；确认后不原地改SKU、数量或分配，错误通过受控冲销/更正单处理。

## 交接单SKU行

一次实际交接中的一种SKU及包装；不直接绑定某一个订单。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 交接单 | linkOne → handover_docs | 所属单据 |
| 凭据行号 | integer | 单据内唯一 |
| 产品SKU | linkOne → skus | 实际交接SKU |
| 包装规格 | linkOne → packaging | 按箱输入时必须已确认换算 |
| 交接数量 | decimal | 按实际输入单位保存的正数 |
| 输入单位快照 | text | 箱/件/套等 |
| 基础单位换算快照 | decimal | 只取当时已确认的正换算，不随主数据改变 |
| 基础单位数量 | derived | 数量×换算；需要整数件时拒绝分数 |

- 一张物理凭据上的总数量只记一次，再由履约分配拆给多个订单，避免重复计提。

## 履约分配

一条交接行分配给某条订单明细的基础数量。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 交接单SKU行 | linkOne → handover_lines | 实际凭据来源 |
| 批次SKU明细 | linkOne → order_lines | 履约归属 |
| 分配基础数量 | decimal | 正数；同张交接行的分配合计必须等于实交数量 |
| 对应计划 | linkOne → line_plans | 可空；不固定时间的提货也可直接落到订单明细 |
| 原提货分配 | linkOne → allocations | 实际退回必须可追溯原已提分配 |
| 退回后处理 | singleSelect | 需要补提/不再补提/待确认；不从退回动作自动推断 |

- SKU、基础单位、渠道必须与所关联单据/订单一致。
- 同一SKU的一次提货可分配到多个批次；只计物理数量一次。
- 退回累计不得超过该原分配可退量；需要补提的退回才重新打开履约需求。

## 订单数量变更

对某条订单明细的一次有依据的增减、关闭或重开余量。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 批次SKU明细 | linkOne → order_lines | 受影响明细 |
| 动作 | singleSelect | 增加下单量/减少下单量/关闭余量/重开余量 |
| 基础数量 | decimal | 正数，方向由动作确定 |
| 原因 | longText | 必须有渠道确认或业务依据 |
| 确认状态 | singleSelect | 草稿/已确认/已冲销 |
| 依据 | attachment | 经确认的改单/余量关闭依据 |

- 关闭余量不是提货；已关闭部分不进入待提货。
- 不能直接把当前数量减到已履约数量和已关闭余量之下。

## 跟进记录

一条共享或单独的业务文字说明，不能代替数量凭据。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 渠道订单批次 | linkOne → order_batches | 批次级说明可只挂批次 |
| 相关SKU明细 | linkMany → order_lines | 需要时挂多条明细 |
| 内容 | longText | 保留历史共享备注 |
| 业务记录日期 | date | 未知时空，不用导入日充当历史日期 |
| 来源行 | linkOne → source_rows | 精确原始出处 |


## 期初履约确认

一条经审核的历史余额说明；不是编造的历史提货单。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 批次SKU明细 | linkOne → order_lines | 每明细每有效截点只有一套余额 |
| 历史截点 | date | 明确到日；边界后新单据才计增量 |
| 累计提货期初 | decimal | 未知与0分开 |
| 累计退回期初 | decimal | 必须确认，不从历史散文编造 |
| 已履约期初 | decimal | 退回处理差异须在说明中体现 |
| 关闭余量期初 | decimal | 已完结不能自动推导全部提货或全部关闭 |
| 已审核 | checkbox | 未经审核权威余额不显示为零 |
| 依据及假设 | longText | 保留确认人和证据 |


## 导入快照

一次原文件快照；与业务订单批次分开。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 文件名 | text | 原件保存在受限存储 |
| 文件哈希 | text | 同快照重跑幂等 |
| 映射版本 | text | 可重放 |
| 导入时间 | dateTime | 不作为业务日期 |


## 原始台账行

原表一行观察记录；先核对其批次、SKU和计划粒度。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 导入快照 | linkOne → import_batches | 对应文件 |
| 工作表 | text | 原标签 |
| 行号 | integer | 来源定位，非业务ID |
| 白名单原值 | longText | 排除凭据、隐藏页和非业务字段 |
| 归属核对 | singleSelect | 正式订单/分月计划/意向需求/重复快照/待确认 |
| 对应订单批次 | linkOne → order_batches | 渠道编号确认后关联 |
| 对应SKU明细 | linkOne → order_lines | 不能用源行号代替稳定明细ID |
| 对应计划 | linkOne → line_plans | 需要时映射计划节点 |

- 新文件SHA改变时不能直接追加另一套订单；先核对稳定业务身份。

## 数据核对

一个数据冲突、缺失或归并问题。

| 字段 | 逻辑类型 | 含义 |
| --- | --- | --- |
| 来源行 | linkOne → source_rows | 原始证据 |
| 问题类型 | singleSelect | 条码/料号/批次/品牌/计划节点/状态数量等 |
| 处理状态 | singleSelect | 未处理/处理中/已解决/暂缓 |
| 处理结论 | longText | 不覆盖原始证据 |
